# Decisões arquiteturais

Cada arquivo registra uma decisão aprovada e suas consequências. Numere em sequência (`0001-slug.md`, `0002-slug.md`); não altere o sentido de uma ADR aceita sem registrar uma nova decisão que a supere.

Use o modelo local [`../_templates/adr.md`](../_templates/adr.md). O canon apresenta o estado vigente e aponta para as ADRs; esta pasta não contém decisões aprovadas ainda.
